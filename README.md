# Portfólio — Gustavo Henrique Bigatão

Portfólio pessoal em React + Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Editar conteúdo

- **Projetos**: `src/data/projects.js` — inclua `image`/`video` (caminho em `public/`) e `github`/`demo` quando disponíveis.
- **Tecnologias**: `src/data/technologies.js`.
- **Links de contato (LinkedIn, GitHub, e-mail)**: `src/data/siteConfig.js`.

## Mídia dos projetos

Coloque imagens/vídeos em `public/projects/` e referencie em `src/data/projects.js`
(ex: `image: "/projects/bgt-fit-cover.jpg"`). Até lá, os cards mostram um placeholder.
